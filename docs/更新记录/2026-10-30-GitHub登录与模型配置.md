# 2026-10-30 GitHub 登录与模型配置增量

## 1. 一句话摘要

后端新增 GitHub OAuth 登录/账号绑定、用户级 GitHub Token、管理员 OpenAI/Anthropic 模型配置和用户偏好模型；完成 26 个后端用例、本地 mock 外部服务真实浏览器联调，并同步本地库与文档。

## 2. 背景与目标

- 原需求 F18 至少支持一种登录方式；本轮在现有 Sa-Token + 账号密码体系上增加 GitHub 登录，并与账密登录并存。
- 已绑定用户拉取 PR 时使用自己的 GitHub token；未绑定用户/游客按公用 token → 无 token 降级，避免所有请求共用一份 token。
- 管理员成为模型配置的唯一入口，支持 OpenAI Chat Completions 与 Anthropic Messages 两种格式；普通用户只能从 enabled 模型中选择偏好。
- 不引入 JWT、Spring Security 或替换 Sa-Token；不修改 `frontend/`。

## 4. 设计说明

| 主题 | 方案 |
| --- | --- |
| GitHub 身份 | 独立 `user_github_binding` 一对一表；`github_id` 唯一，login/avatar/email 只作展示 |
| OAuth | 后端 state 一次性 Redis 凭证；回调只 302；登录 ticket 一次性兑换原体系双 token |
| Token 加密 | AES-256-GCM，`PR_SECURITY_ENCRYPTION_KEY` Base64 32 字节；随机 IV；`v1:` 前缀；previous key 支持轮换 |
| Token 选择 | 已绑定用户 token → 公用 token → 无 token；401 只标记用户 token 失效，不静默回退 |
| 模型配置 | `ai_model_config`；API Key 加密、末 4 位掩码；默认模型唯一；停用默认自动提升另一个 enabled 模型 |
| 模型运行时 | 用户偏好 → 管理员默认 → 环境兜底；重试优先原任务模型；任务写 `model_config_id` 和 `analysis_config.model` 快照 |
| Anthropic | 独立 Messages 客户端映射 system/tool_use/tool_result；thinking 只对支持的环境 DeepSeek 发送 |
| SSRF | 生产只允许 HTTPS 公网 443，拒绝 localhost/私网/链路本地/元数据/重定向；本地联调用 `allow-private-base-url` 显式放开 |
| 解绑安全 | GitHub 创建且 `password_set=0` 的账号必须先设置密码再解绑 |

## 5. 一致性与权限

- 普通用户访问 `/api/admin/model-configs/**` 返回 403；只能读取 `/api/models/available`。
- `preferredModelId` 必须是 enabled 模型；非法 ID 返回 400；`0` 表示清除偏好。
- 模型配置变更清除用户设置缓存；历史任务/报告使用任务快照，不随当前配置改名/停用改变。
- 任务子资源继续统一走 `TaskAccessService`；GitHub token 不写入任务表。
- 预览缓存只缓存无 token 公开请求；用户/公用 token 预览不走共享缓存。
- 日志、接口、文档、提交中不出现真实 GitHub token、模型 Key 或数据库密码。

## 7. 风险与后续

- 真实 OAuth App 回调地址必须与 `PR_GITHUB_OAUTH_CALLBACK_URL` 完全一致；需在 GitHub 后台登记。
- 生产必须配置并妥善保管 `PR_SECURITY_ENCRYPTION_KEY`；密钥丢失会导致已有 token/Key 无法解密。
- 本期未开放任务级临时模型切换；私有 PR 仍依赖后续 scope/授权策略评估。
- 已有数据库卷没有新增 migration 脚本，生产上线前需按目标库情况评估 DDL。
- Docker/Nginx 仍未在目标机复验。

## 8. 汇报口径

1. 本轮把 GitHub 从“服务端单一公用 token”升级为“登录身份 + 用户 token + 公用/无 token 降级”，并把 token 解析收敛到一个 service，预览和异步任务口径一致。
2. 管理员可以配置 OpenAI/Anthropic 两种模型，Key 加密存储、接口只返回掩码；普通用户只能选 enabled 模型，停用后自动回退默认。
3. 任务会固化模型快照，历史报告不受后续配置改名/停用影响；模型和 GitHub 的外部调用都有超时、限流和错误分类。
4. 已完成 26 个后端用例、18080 真实浏览器联调和本地库同步；真实 OAuth/Anthropic 凭据和 Docker/Nginx 目标机验证仍待补。
