# 部署与安全检查

> 范围：后端、MySQL、Redis 与 Nginx 反向代理。正式前端由前端负责人构建部署；本仓库只保留 Nginx 占位页，部署改动不涉及 `frontend/`。

## 1. 部署材料

| 文件 | 用途 |
| --- | --- |
| `backend/Dockerfile` | JDK 17 多阶段构建，运行镜像使用非 root 用户 |
| `backend/.dockerignore` | 排除本地配置、日志、构建产物和 Git 元数据 |
| `deploy/docker-compose.yml` | MySQL 8.4 + Redis 7.4 + Backend + Nginx |
| `deploy/.env.example` | 密钥占位符；复制为 `deploy/.env` 后填写 |
| `deploy/nginx/default.conf` | 反向代理 `/api/`，静态文件回退到 SPA index |
| `deploy/nginx/html/index.html` | 前端未构建时的占位页；正式前端由前端负责人替换 |
| `deploy/sql/schema.sql` | 首次创建 MySQL 卷时自动初始化 |
| `deploy/sql/migration-20261022-retry-of-task.sql` | 已有数据卷的任务重试字段迁移 |
| `deploy/sql/migration-20261023-rename-sys-user-to-user.sql` | 已有数据卷的账号表 `sys_user → user` 迁移 |

## 2. 启动步骤

```bash
cd deploy
cp .env.example .env
# 编辑 .env：MySQL/Redis 密码、模型 Key、GitHub Token、公开地址
docker compose up -d --build
docker compose ps
docker compose logs -f backend
```

只部署后端时：

```bash
docker compose build backend
docker compose up -d mysql redis backend
```

访问 `http://localhost/`；API 在 `http://localhost/api/`。

后端以 `prod` profile 启动，配置来源为 `backend/src/main/resources/application.yml` 与 Compose 注入的环境变量；镜像中不包含 `application-dev.yml`。

首次启动时 MySQL 自动执行 `schema.sql`。如果 `mysql-data` 卷已存在，schema 不会重复执行；按日期顺序手动执行迁移脚本：

1. `deploy/sql/migration-20261022-retry-of-task.sql`
2. `deploy/sql/migration-20261023-rename-sys-user-to-user.sql`

已执行过的迁移不要重复执行。

### 2.1 后端环境变量

| Compose 变量 | Spring 配置 | 必填 | 说明 |
| --- | --- | --- | --- |
| `SPRING_PROFILES_ACTIVE` | `spring.profiles.active` | 是（Compose 固定 `prod`） | 生产 profile |
| `PR_DATASOURCE_HOST` / `PR_DATASOURCE_PORT` / `PR_DATASOURCE_DATABASE` | `pr.datasource.*` | 是 | MySQL 连接 |
| `PR_DATASOURCE_USERNAME` / `PR_DATASOURCE_PASSWORD` | `pr.datasource.*` | 是 | MySQL 业务账号 |
| `PR_REDIS_HOST` / `PR_REDIS_PORT` / `PR_REDIS_PASSWORD` / `PR_REDIS_DATABASE` | `pr.redis.*` | 是 | Sa-Token、refresh-token、P0 缓存 |
| `PR_AI_PROVIDER` | `pr.ai.provider` | 否 | 默认 `deepseek`；`fake` 仅用于联调 |
| `PR_AI_DEEPSEEK_API_KEY` / `PR_AI_DEEPSEEK_BASE_URL` / `PR_AI_DEEPSEEK_MODEL` | `pr.ai.deepseek.*` | 真实分析时必填 | OpenAI 兼容中转站 |
| `PR_AI_ALLOW_PRIVATE_BASE_URL` | `pr.ai.allow-private-base-url` | 否 | 默认 `false`；本地自建模型才设为 `true` |
| `PR_GITHUB_TOKEN` | `pr.github.token` | 否 | 公开仓库可不填，限流较低 |
| `PR_SECURITY_ENCRYPTION_KEY` | `pr.security.encryption-key` | 是（GitHub 绑定/模型 Key） | Base64 编码的 32 字节 AES-256 密钥 |
| `PR_SECURITY_ENCRYPTION_KEY_PREVIOUS` | `pr.security.previous-encryption-key` | 否 | 轮换期间只用于解密旧数据 |
| `PR_GITHUB_OAUTH_CLIENT_ID` / `PR_GITHUB_OAUTH_CLIENT_SECRET` | `pr.github.oauth.*` | GitHub 登录/绑定时必填 | OAuth App 凭据，只放环境变量 |
| `PR_GITHUB_OAUTH_CALLBACK_URL` | `pr.github.oauth.callback-url` | 是 | GitHub OAuth App 登记的后端回调 |
| `PR_GITHUB_OAUTH_FRONTEND_LOGIN_CALLBACK_URL` / `PR_GITHUB_OAUTH_FRONTEND_BIND_RESULT_URL` | `pr.github.oauth.*` | 是 | 前端登录完成页/绑定结果页 |
| `PR_GITHUB_OAUTH_SCOPES` | `pr.github.oauth.scopes` | 否 | 默认 `read:user user:email` |
| `PR_APP_FRONTEND_BASE_URL` | `pr.app.frontend-base-url` | 是 | 生成游客分享链接的外部地址 |
| `LOG_DIR` | `logback-spring.xml` 的 `LOG_DIR` | 是（Compose 固定 `/app/logs`） | 日志目录 |

JDBC driver 默认 `com.mysql.cj.jdbc.Driver`；切换数据库时可用 `PR_DATASOURCE_DRIVER_CLASS_NAME` 覆盖。

## 3. 安全检查

- [x] `application-dev.yml` 在 `.gitignore` 和 `.dockerignore` 中，不进入仓库或镜像。
- [x] `prod` profile 不依赖 `application-dev.yml`；Compose 只注入环境变量，镜像内不含本地配置。
- [x] JDBC driver 使用默认值；连接信息缺失时启动失败，不会静默使用错误配置。
- [x] `.env` 不提交；`.env.example` 只有占位符。
- [x] 后端镜像使用非 root 用户，日志目录权限限定为应用用户。
- [x] MySQL/Redis 只在 Compose 内部网络暴露，不映射宿主机端口。
- [x] Nginx 添加 `X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy`；请求透传 `X-Request-Id`。
- [x] 应用日志统一脱敏 Authorization、token、password、api-key；不记录完整 prompt/代码。
- [x] 健康检查覆盖 MySQL、Redis；后端启动依赖两者健康。
- [ ] 生产必须修改 `schema.sql` 的 admin/demo 默认密码，或删除种子账号。
- [ ] 生产必须变更 `.env` 中示例密码，并把模型 Key/GitHub Token 放在密钥管理系统。
- [ ] `PR_SECURITY_ENCRYPTION_KEY` 必须是 Base64 32 字节密钥，并与本地/其他环境隔离；轮换时先用 previous key 解密再重加密。
- [ ] GitHub OAuth App 回调地址必须与 `PR_GITHUB_OAUTH_CALLBACK_URL` 完全一致；secret 不进入前端、日志或仓库。
- [ ] 生产保持 `PR_AI_ALLOW_PRIVATE_BASE_URL=false`，管理员模型 base URL 只允许 HTTPS 公网地址。
- [ ] 普通用户只能读取 `/api/models/available`，不能访问 `/api/admin/model-configs/**`。
- [ ] 生产必须由外部负载均衡或 Nginx 终止 TLS；当前配置只监听 HTTP。
- [ ] 备份 `mysql-data` 和 `backend-logs` 卷，定义保留周期。
