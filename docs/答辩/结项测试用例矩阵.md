### 3.1 p-queue#226 跨文件类型契约

- PR：`https://github.com/sindresorhus/p-queue/pull/226`
- 提交版本：`df967b5f0430e3142a697d9f208c545e95ccc61c`
- 任务：`#16`
- 变更文件：`source/index.ts`、`test-d/index.test-d.ts`
- 模型输出：4 条问题，3 条人工确认采纳，1 条待确认，成功导出 [样例报告](样例报告.md)
- 人工复核：
  - `source/index.ts` L16 新增 `OptionsType` 泛型，默认值为 `Options<...>`，条件类型只检查构造选项；
  - `source/index.ts` L277 的 `add` 条件类型不读取单次调用 `options.throwOnTimeout`；
  - `source/index.ts` L335-336 的 `addAll` 重载把 `options` 从可选改为必填；
  - `test-d/index.test-d.ts` L17/L18 分别断言 `add`/`addAll` 在 `throwOnTimeout:false` 时返回含 `void` 的类型，与实际签名冲突；
  - 该 PR 已关闭，CI 在 Node 18/20 上失败，与上述类型契约风险一致。
