- 任务 `#16`（`p-queue#226`）已预创建；现场只展示，不要删除或重跑；如需重跑，使用真实模型配置。

## 3. 正常链路（2–3 分钟）

1. **登录**：demo 登录，展示任务列表和用户菜单。
2. **无效 URL**：输入 `not-a-pr-url`，展示 400 明确错误（可选，10 秒）。
3. **预览真实 PR**：粘贴 README PR，点击预览。
   - 预期：`octocat/Hello-World #11596`、作者、分支、head SHA、1 文件、+2/−0。
4. **创建任务**：报告语言选中文，点击开始分析。
   - 预期：跳转任务详情，status 1 排队 → 2 分析中 → 3 完成。
   - 进度来自 `/tasks/{id}/progress`，刷新不丢。
5. **报告**：展示 purpose/changes/impacts、覆盖范围、重点文件。
   - 说明：报告不是“代码正确”的证明，未发现问题≠无缺陷。
6. **文件 Diff**：
   - 打开 README 文件，展示 add 行、结构化行号、问题标记。
   - 打开问题详情，展示证据/建议/置信度；报告级问题没有文件行号。
7. **问题反馈**：把一条问题改为已采纳，填写理由；再撤销，状态回待确认。
8. **导出**：下载 Markdown，展示 PR 信息、提交版本、总结、风险、未覆盖范围。
9. **版本对比**：选择同 PR 的另一个已完成任务，展示 added/remaining/resolved 与总结变化。
   - 如果准备了两个任务：说明行号偏移/低置信匹配提示。

### 3.2 GitHub 身份与模型配置增量（1–2 分钟，可选）

1. **GitHub 登录**：登录页点击“使用 GitHub 登录”，展示跳转 GitHub、回调 ticket 兑换、登录后 `passwordSet`/绑定状态。
   - 预期：新用户用户名为 `gh_{login}`；已绑定用户直接登录原账号；GitHub token 不出现在 URL/前端。
2. **绑定/解绑**：demo 账号绑定 GitHub，展示 `githubLogin/scope/tokenStatus/authorizedAt`；解绑前检查 `passwordSet`。
3. **管理员模型配置**：admin 打开模型配置页，新增/测试 OpenAI 或 Anthropic；列表只显示 `****` 掩码。
4. **用户偏好**：demo 选择管理员 enabled 模型，创建任务；详情/报告显示 `modelDisplayName/modelProvider` 和 `analysisConfig.model` 快照。
5. **停用回退**：管理员停用该模型，刷新设置，展示 `preferredModelEnabled=false`、`effectiveModel` 回退默认；新任务使用回退模型，历史任务仍显示原快照。
6. 兜底：没有真实 OAuth/Anthropic 凭据时，使用本地 mock 或预置任务；明确说明真实凭据待验收，不把 mock 说成真实授权。

## 4. 游客链路（30 秒，可选）

## 6. 兜底方案

1. 网络/GitHub 不可用：切 fake provider，使用预创建任务，展示完整页面。
2. 模型慢/超时：直接展示预置失败任务和重试入口，不现场重跑。
3. 大 PR 太慢：只展示任务详情/覆盖统计，不点击全量 Diff。
4. 前端异常：用 Swagger/接口结果和 Markdown 报告兜底；说明 API 已通过 40/40 回归 + 26 个后端单测。
5. GitHub OAuth/Anthropic 无真实凭据：使用本地 mock 或预置绑定/模型配置，明确说明真实凭据待验收。
6. 数据库/Redis：提前启动并保留预置数据；演示前不要清库。
